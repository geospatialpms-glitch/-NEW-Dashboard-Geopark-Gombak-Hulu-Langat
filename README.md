# Dashboard Geopark Gombak - Hulu Langat

Dashboard prototaip untuk modul **Selangor Urban Observatory (SUO)** yang memfokuskan Geopark Gombak–Hulu Langat.

## Kandungan
- Peta interaktif geotapak G1–G20
- Carian dan penapisan kategori geologi
- Hierarki Pusat Eksplorasi, Pusat Satelit, Kiosk Geotapak serta Penanda & Panel
- Ringkasan komposisi geotapak
- Cadangan modul pemuliharaan, geopelancongan, kemudahan, komuniti dan kawalan pembangunan

> Nota: koordinat dan sempadan pada versi prototaip adalah indikatif dan perlu diganti dengan data GIS rasmi untuk penggunaan operasi SUO.
